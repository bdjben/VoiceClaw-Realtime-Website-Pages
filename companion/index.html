Companion FAQ

What the bridge does and does not do.

The Companion repository includes detailed installation, privacy, and route notes.

Read the repository guide
Do I need Companion for GPT Realtime?

No. Device-only GPT Realtime can work without a Mac. Companion is for Codex, OpenClaw, Hermes, Mac files, and other computer-backed routes.

What does Install and Start change?

It creates the local bridge configuration, installs a per-user LaunchAgent, starts the bridge, and configures the selected Tailscale Serve mapping. Companion explains each change before it runs.

Does Companion make my Mac public?

Not by default. The local bridge listens on 127.0.0.1 and is published privately through Tailscale Serve. A public HTTPS tunnel is optional, advanced, and only used when you configure it.

Where do returned files go?

Supported route outputs appear in the Companion Artifact Inbox. The inbox is bounded, authenticated, and manually managed; files are not silently evicted.

Setup help

Pairing or route check not passing?

Send the visible state and the route you are trying to use. Do not send API keys, QR payloads, tokens, or private bridge URLs.
