Troubleshooting

Start with what you can see.

No voice input or output

Confirm microphone permission, the visible mute state, the selected Voice Engine, and the audio output. End and restart the live session after changing audio permissions.

Companion is unreachable

Open Companion Diagnostics. Confirm the local bridge, Tailscale Serve mapping, and current phone URL. Re-pair after any bridge port or setup payload change.

Codex, OpenClaw, or Hermes fails

Check the status for the agent you selected. In Companion, verify the selected Codex installation, the OpenClaw folder containing openclaw.json, or the configured Hermes executable.

Watch cannot reach a computer route

Codex, OpenClaw, and Hermes can use the paired iPhone when it is nearby. Without the iPhone nearby, those computer-side agents require your own personal HTTPS tunnel. GPT Realtime, GPT Live, and GPT-5.6 Direct do not require that tunnel.

GPT Live connects but does not hear or reply

End and restart the session once, then confirm microphone permission, the visible mute state, audio output, and current ChatGPT sign-in. If GPT Realtime works but GPT Live remains silent, send support the exact status message and diagnostics instead of changing unrelated Companion or agent settings.

Codex computer control is blocked on Windows

Open Companion and confirm Codex access is enabled, the selected Windows Codex installation passes its check, and Companion has the permissions granted during installation. If only computer-control requests fail, send support the exact Windows helper or permission message shown.

Setup paths

Prepare only what you plan to use.

Device-only voice

Install the iPhone app, connect supported ChatGPT or OpenAI access, allow the microphone, and start GPT Realtime or GPT Live. A computer is not required.

Computer routes

Install the latest Companion, prepare Tailscale, start the connection, pair by QR, and run Ready Check for the agent you want to use.

Apple Watch

Install or open the Watch app and sync current settings from iPhone. GPT Realtime, GPT Live, and GPT-5.6 Direct can use Watch Wi-Fi or cellular without a personal HTTPS tunnel. Codex, OpenClaw, and Hermes use the paired iPhone when it is nearby; they use your personal HTTPS tunnel only when the iPhone is not nearby.

Files and actions

Allow the iPhone or computer permissions needed for the action. Open returned files from Work in VoiceClaw Realtime or Tasks & Files in Companion.

Common questions

Answers for the issue you see.

These checks reflect the current Companion and onboarding flow.

Why is GPT Realtime or GPT Live not starting?

Confirm microphone access, then check that ChatGPT subscription sign-in or an OpenAI API key is available for the Voice Engine and Voice Route you selected. If authentication imported from Companion changed, pair the iPhone again.

Why can iPhone not reach Companion?

Confirm Companion is running, Tailscale is signed in on both devices, both are on the same tailnet, and the current Tailscale Serve mapping passes Companion Diagnostics. If the bridge port changed, scan the current QR again.

Why is an OpenClaw agent missing?

In Companion, point OpenClaw Install Path at the folder that directly contains openclaw.json, usually ~/.openclaw. Then run the route check again.

Why does Hermes fail even though it is installed?

Run hermes --help in Terminal or PowerShell. Companion uses your computer's command-line environment. If Hermes works only through custom shell setup, configure its executable path in Companion.

Why can Apple Watch talk to GPT but not reach my computer?

GPT Realtime, GPT Live, and GPT-5.6 Direct can use the Watch's Wi-Fi or cellular connection without a personal HTTPS tunnel. Codex, OpenClaw, and Hermes can use the paired iPhone when it is nearby. To reach those computer-side agents without the iPhone nearby, configure your own personal HTTPS tunnel to Companion.

What should I include in a support email?

Include the device, app or Companion version, selected route, the visible status message, and what happened immediately before the issue. Redact API keys, QR payloads, tokens, private hostnames, and bridge URLs.
